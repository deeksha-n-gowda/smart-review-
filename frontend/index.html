How Smart Review works

Smart Review is a free AI code review assistant. It statically analyses your source files, ranks every finding by severity, and shows why each vulnerability was flagged — so you can fix real problems instead of chasing false positives.

  1. 1

    Upload your code

    Create a project and drop in .py, .java, .cs or .js files — or upload a whole project at once. Files are encrypted with AES-256-GCM before they are stored, and each file is analysed independently.

  2. 2

    Get a severity-ranked report

    The analyzer combines rule-based static analysis (SQL injection, hardcoded credentials, unsafe crypto, weak hashing and more) with structural metrics such as cyclomatic complexity. Every finding is scored critical, high, medium or low, and each file receives its own risk score.

  3. 3

    Understand it, then fix it

    Open any finding to see the vulnerable line, a plain-English explanation, the SHAP and LIME feature attribution charts that justify the score, and a suggested fix you can export as a PDF report.

Frequently asked questions

What is AI code review, and how is it different from a manual review?

A manual review is limited by time and attention: a reviewer can only read so many lines before fatigue, and rarely checks every branch of every function. AI code review applies the same rule set to every file you upload, consistently. It does not replace a human reviewer — it removes the mechanical work (finding the obvious SQL injection in line 8) so the reviewer can spend their time on architecture, business logic and trade-offs. With Smart Review you get both: a machine-checked baseline plus an explanation of why each finding matters.

How do I find security vulnerabilities in my code before release?

Start with static analysis on every file — that catches injection flaws, hardcoded secrets, weak cryptography and dangerous API usage before the code ever runs. Then add a layer of review for the bugs a scanner cannot see: missing authorisation checks, business-logic abuse and insecure design. Smart Review performs the first step automatically and explains the results, so you can focus manual review on the parts that genuinely need a human. Review findings by severity: fix critical and high issues first, then work down the list.

Which programming languages does Smart Review support?

Python (.py), Java (.java), C# (.cs) and JavaScript (.js, .mjs) are supported today. Each language has its own rule set and parser — Python is analysed with its AST and pylint, Java with javalang, and the C# and JavaScript analysers use dedicated pattern and structure checks. You can mix languages inside the same project, and each file is scored independently.

What does "explainable AI" mean here — what are SHAP and LIME?

A black-box score ("this file is 78% risky") is not actionable. Smart Review shows why a file was scored that way using two well-established explainability methods. SHAP (SHapley Additive exPlanations) attributes the risk score across the individual features that produced it, so you can see which patterns contributed most. LIME (Local Interpretable Model Explanations) explains each finding locally by looking at the exact lines around the flagged code. The two views complement each other: SHAP gives you the file-level picture, LIME gives you the line-level reason. Both are available in the Detail tab of the analysis panel.

Is Smart Review free? Do I need an account or a credit card?

Yes — Smart Review is free, and you do not need to sign up, create an account or enter a credit card. Create a project, upload your files and the analysis runs immediately. There is no trial timer and no feature gate on the vulnerability report, the explainability charts or the PDF export.

Is my source code secure? What happens to the files I upload?

Your source code is encrypted at rest with AES-256-GCM before it is written to the database, so the stored blob is not readable as plain text. Analysis runs on the encrypted-at-rest copy and the decrypted content is only materialised in memory while a file is being scanned. You can delete a project at any time.

How long does an analysis take, and can I review multiple files at once?

A typical single file is analysed in a couple of seconds, and a project with many files is processed file by file so one slow file never blocks the rest. Once the analysis is done, the review page gives you a tab per file — switch between them to compare the source, the risk score and the vulnerability list for each file without leaving the page. The URL updates as you switch, so you can bookmark or share a link to one specific file's analysis.

Can I share or export the analysis results?

Yes. Use the Export button in the review toolbar to produce a clean, print-ready report you can save as a PDF or share with your team. The report contains the file summary, the risk score and the full list of findings with their explanations.
